# Clock of Clocks

## Vision
Relógio funcional onde cada dígito da hora é formado por ponteiros de mini-relógios analógicos — sincronizados em tempo real. CSS puro com JS mínimo para lógica de tempo.

## Objetivos
- Display HH:MM sincronizado com hora real
- Cada dígito = grid de mini-relógios analógicos (ponteiros estilizados)
- Zero dependências externas
- Monetizável: poster digital / produto físico / componente pago

## Stack
- HTML5 + CSS3 (animations, custom properties, grid)
- JavaScript vanilla (só lógica de tempo — sem frameworks)
- Single-file deliverable (index.html autossuficiente)

## Produto
- `index.html` — demo interativa
- Versão poster: fundo escuro, resolução alta, sem interação
- Versão componente: exportável como Web Component
